## Context

跨计划事项的直接关联由子事项的 `parent_id` 表示。详情弹窗已用于长期、周、日和稍后事项。工作台只加载当前选中的周和日，不能以界面缓存推导完整子项列表。

## Decisions

- 按被查看事项的 ID 从数据库查询直接子项，并按其所属计划层级限制结果：长期目标对应周或日，周事项对应日。查询覆盖所有日期，包括当前工作台未加载的计划。
- 只返回已确认且有标题的事项；不遍历后代，不列出同周期子步骤。按日期及计划内顺序稳定排列。
- 详情底部用只读列表展示标题、层级和日期，并提供加载、失败及空状态。使用现有弹窗正文滚动区域；保存备注和焦点返回行为沿用原逻辑。
- 任务变更事件和本地任务操作使该只读查询缓存失效，确保重新打开时获取最新关联。

## Verification

- 后端测试覆盖跨日期的周、日直接子项，以及同周期子步骤和间接后代的排除。
- 前端测试覆盖长期目标的列表渲染和周事项的空状态，并执行 TypeScript 构建。
