## ADDED Requirements

### Requirement: 递归删除影响确认

系统 MUST 在通过 GUI 删除带关联子目标或子计划的目标前展示确认弹窗，明确递归删除的范围和数量。周期容器删除 SHALL 同时说明子周期、目标与专注块的实际影响。取消不写入；确认与删除之间影响发生变化时 MUST 重新确认。影响范围仅依据明确的从属关系，不因任务与专注块处于同一天而推断关联。

#### Scenario: 删除有后代的目标
- **WHEN** 用户删除长期目标，该目标下存在关联的周任务和日任务
- **THEN** 弹窗明确这些后代也会删除，用户确认后一次性删除，并刷新所有涉及日期和周期

#### Scenario: 删除日计划
- **WHEN** 用户删除包含专注块的日计划
- **THEN** 弹窗列出子目标和专注块数量，确认后删除其明确从属的内容

#### Scenario: 取消或影响变化
- **WHEN** 用户取消弹窗，或确认前关联内容已增加/移除
- **THEN** 取消时保持全部内容，影响变化时拒绝旧确认并重新加载影响

#### Scenario: 同日其他内容
- **WHEN** 用户仅删除一项日任务，该日另有独立专注块
- **THEN** 不把同日作为关联关系，不删除这些独立专注块，弹窗按实际影响显示
