## Context

长期周期目前仅支持固定产品月；`DurationDialog` 的进度检查只是按半程推导的前端展示，并没有可保存的检查配置。周期层级与目标的 `parent_id` 关联是两棵树；专注块属于日周期，目前没有目标与专注块的直接关联字段。

## Goals / Non-Goals

**Goals:** 扩展现有周期以持久化自定义日期和检查节奏；完整显示递归删除的实际影响；修复语言与滚动条反馈。

**Non-Goals:** 不新增任务/目标实体，不将检查日自动创建为任务或专注块，不引入新的通知调度器，不根据同日或同名推断目标与专注块关联。

## Decisions

1. `CreateCycleArgs` 增加 `starts_on`、`ends_on` 和 `progress_check`。预设仍使用 `duration_months`；自定义显式日期与预设参数互斥。自定义时长由本地日期差得到，允许非整周，日期比较与校验下沉 `domain/calendar.rs`。
2. 在已有 `cycles` 增加可空 JSON 列 `progress_check`，值为 `{kind:"once",date:"YYYY-MM-DD"}` 或 `{kind:"repeat",every_days:N}`；运行时使用封闭枚举。不增加检查实例表。数据库约束限制为长期周期和有效配置形状，服务验证日期范围。预设周期继续以半程作为默认一次检查。
3. 创建弹窗追加“自定义”卡片，右侧上部为起止日期，下方检查方式二选一。检查方式使用无通栏底色的圆点单选行。定期方式按“每隔 + 短数字输入 + 自然宽度的天/周菜单”排列，不拉伸到整行；指定一次使用紧凑日期行。两种草稿独立保留，预览最多显示前几个日期和总次数，避免长周期撑高弹窗。已创建周期在日期旁显示实际检查节奏的轻量文字入口，点击用既有浮层查看安排，不增加常驻通栏。检查安排是规划信息，沿用现有复盘入口；自动提醒不在本次引入。
4. 删除预览从两棵树的实际 FK 闭包产生：周期子树中的任务及其跨周期后代均计入；专注块仅随所属周期子树删除。目标只级联目标后代，不删除同日独立专注块。复用现有周期删除弹窗，任务新增同风格弹窗，仅有后代时额外确认。
5. 预览带由影响对象计算的 token；GUI 删除命令重新计算并检查 token，变化时重新确认。实际删除清理全部后代提醒、预览锁与关联查询失效。Coach 已有确认流程继续单一入口，不叠加第二个 GUI 弹窗。
6. 关联工作台主横向滚动容器与关联条使用局部 scrollbar 样式；细线、透明轨道、主题颜色，不全局改动其他滚动区域。
7. 主工作台默认把纵向为主的普通滚轮映射为横向移动。计划卡和专注块的实际内容滚动区仍只有在鼠标主键明确点击后才纵向滚动；标题、外围容器、Tab 和程序聚焦不激活内容区。周、日时间导航是独立例外：指针悬停在某个导航鼓轮上时，该鼓轮独占纵向滚轮并抑制工作台横向路由，不需要点击或取得焦点；离开后恢复默认横向路由。内容体自身 `data-wheel-active="true"` 时，现有标题预留位置仅显示 14px 中性的不可交互上下 SVG 图标；不显示可见文字，但保留本地化无障碍标签（中文“上下滚动”，英文“Vertical scroll”）和解释滚动行为的原生 tooltip。未激活时隐藏提示但保留空间，不出现背景、胶囊或新行，也不改变布局。提示沿用现有语义色 token。时间导航可使用仅图标并保留可访问名称和 tooltip。空内容和滚动边界仍保持内容区的既有模式，用纵向 overscroll containment 限定区域。明显横向手势及 Ctrl/Meta 缩放保持原行为，纵向手势中的微小横向分量不导致两轴一起移动。
8. 按用户指定的 UI UX Pro Max 复核现有视觉语言：检查方式与时长选项采用单一 Tab 停靠和方向键切换，浮层关闭恢复焦点；控件使用稳定的局部颜色反馈。保留现有语义色与 IBM Plex Sans，不另建视觉系统。
9. 周导航只使用现有周期数据、日期计算和选择状态，不增加数据或后端字段。周鼓轮以日期选择器式固定行高和固定视口展示真实周起始日期，跨日历年保持连续顺序；动态渲染有界窗口，并仅在中心跨过当前行窗口边界时更新有界行集合，禁止循环或重复同一周。当前周身份以内联标签显示在真实周行中，选中状态独立表达；该行按逻辑日期 index 计算自然位置，正常位置可见时跟随内容，离开视口时同一 DOM 行按滚动方向夹到视口顶部或底部，不插入重复行或改变列表高度，也不提供底部返回控件。点击当前周行平滑居中并打开已有计划或空态。无计划的周仍可选中并显示空态，只有明确创建动作才写入。滚轮使用阻尼平滑吸附，中心候选只有在滚轮静止至少 500ms 且吸附运动结束后才提交；中间候选不打开计划面板。点击行、Enter/Space 直接提交；方向键、Page 和 Home（当前周）沿用同一 500ms quiet + settled 条件，视觉动画可平滑或在减少动态效果时即时完成。周用户提交后仅发出一次日鼓轮定位请求：已有周使用保存的起始日，无计划周使用当前周起始设置作为锚点；该程序定位不得发出新的用户提交或反馈循环。首次布局只确保选择项可见，刷新不得重置手动位置；鼓轮行、视口和空态容器保持固定高度，避免布局跳动。
10. 计划卡按内容使用自然高度，设置约 360px 的最小高度，并以工作台剩余可用高度为上限，避免窗口出现纵向溢出，也不把每张卡固定拉伸到整屏。卡片达到上限时，头部保持固定，底部工作量摘要保持固定，只有中部任务行进入该卡片自己的滚动区。专注块侧卡沿用相同的有界卡片高度和独立滚动区；滚动区仍以鼠标主键点击激活，不能因卡片重排改变既有激活语义。

11. 日鼓轮展示与周鼓轮对应的真实日期序列，使用固定行高、固定视口和紧凑星期/日期两行；跨年动态渲染有界窗口并向边缘扩展，禁止循环、重复或因查询范围截断而改变日期身份。今天身份以内联标签显示在真实日期行中；该行按逻辑日期 index 计算自然位置，正常位置可见时跟随内容，离开视口时同一 DOM 行按滚动方向夹到视口顶部或底部，不插入重复的今天行或底部返回控件，也不改变列表高度。点击今天行平滑居中并打开日计划或空态。无日计划的日期可选中并显示空态，浏览和滚轮提交不得创建周期、日计划或专注块；显式创建按钮才写入数据。周起始日来自周期保存边界（创建时采用设置），更改设置不重写旧周期。
12. 周→日与日→周定位严格区分来源。周用户提交、诊断定位或点击当前周行只发出一次日鼓轮程序定位；日用户提交（滚轮静止至少 500ms 且运动结束，或点击/键盘显式选择）选中日期并解析所属周，再发出一次周鼓轮程序对齐。程序定位平滑移动对应鼓轮（减少动态效果时即时移动），不得发出新的用户提交或打开途经日期/周的面板。日鼓轮的滚轮中间状态不切换周计划；只有最终用户提交才展示对应日/周计划或空态。日、周鼓轮行和空态容器保持固定高度，新的滚轮或键盘输入可中断程序定位。
13. 周、日鼓轮共享 500ms wheel quiet debounce 与运动 settled 条件，保留阻尼平滑吸附；方向键、Page、Home（今天/当前周）沿用相同条件防止连续按键打开中间面板，Enter/Space 和点击行是显式用户操作，可直接提交但不得制造额外联动。切换后只显示一组当前周/日内容，查询刷新不能重置手动滚动或重复触发联动。视觉反馈保持克制，不使用大幅位移、缩放或过渡遮罩。

14. 鼓轮的日期身份与格式化标签在滚动开始前按逻辑 index 准备并缓存；连续帧只更新已渲染有界窗口中行的合成位移和透明度，不每帧重建 React 日期行、重复格式化日期或扩大 DOM。只有中心跨过当前行窗口边界时才更新有界行集合，复用已有格式化标签，仅为新增行格式化，不额外引入批量缓冲层；当前周/今天仍是同一 DOM 行，按逻辑位置自然展示或夹到顶部/底部，点击回中与 500ms quiet + settled 提交条件不变。

15. 周、日最终用户提交后的面板同步采用原位内容过渡。目标面板的任务和专注块数据尚未全部就绪时保留旧内容的可见布局，旧内容不可编辑，直到新数据可替换；数据就绪后仅让内容约 160ms ease-in 淡出至 opacity 0，卡片边框和背景保持不透明，再将目标内容原位以约 260ms 缓启动缓停止淡入至 opacity 1。整卡不使用 translate 或 scale；卡片自然高度只在切换期间约 260ms 平缓插值并遵守工作台可用高度上限，不短暂坍塌。快速连续导航从当前显示状态接续，取消或忽略过期的查询回调与过渡提交，只保留最新目标和单一 live 内容树；关系绘制沿用既有 batch query，不改变其查询方式；减少动态效果时跳过动画并在数据就绪后立即切换，仍保留 quiet/settled、来源隔离和不可编辑退出态。
16. 规划工作区的任务、目标、稍后任务和专注块删除采用数据确认后的原位退场。删除 mutation 成功且对应查询结果不再包含条目后，内容约 160ms 淡出，高度或占位约 260ms 收拢，分段重叠，后续行连续让位，不使用弹跳或大位移；退出节点设置 `inert` 和 `aria-hidden`，不能编辑、拖拽或聚焦。取消或失败不触发假消失，递归删除的影响对象同批退场而不逐条排队。快速独立删除按操作身份隔离，不删除新加入或恢复的同 ID 条目；卸载清理挂起动画和回调，减少动态效果时直接移除并在结束后显示空态。整张计划删除沿用既有 `PlanTransition` 平滑切换到下一个计划或空态，包括长期周期；删除 token、确认流程、Coach 入口和数据库契约保持不变。

## Risks / Trade-offs

- 周期与任务关联跨容器，原预览会漏计 → 使用递归任务闭包与去重，不单纯按周期统计任务。
- 自定义日期可跨夏令时且非整周 → 以 ISO 本地日期计算整天差，保留预设周数文案，自定义使用天数。
- 旧周期无检查配置 → 查看时推导既有半程，不重写既有周期数据。
- 删除旧周期的既有保护规则仍有效 → 预览明确阻止原因；本次不扩大历史数据删除权限。
