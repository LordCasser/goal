## Why

长期周期只提供固定时长，无法表达用户自定义起止日期和检查节奏；未选中选项的文案与当前语言不一致。关联视图滚动条和带后代目标的删除操作也需要明确、一致的交互。

## What Changes

- 在 1 / 3 / 6 个月之后增加自定义起止日期；进度检查支持指定一次日期或每隔若干天/周重复，并预览时间安排。
- 检查安排随周期保存，在周期界面可查看，保持本地日期语义；不把检查安排另建为任务实体。
- 修复所有时长选项的即时翻译；关联工作台横向滚动条收细。
- 鼠标滚轮默认横向浏览主工作台；计划卡和专注块等实际内容滚动区仍需鼠标主键点击后才纵向滚动。周、日时间导航改为日期选择器式鼓轮：指针悬停在导航上时，该导航独占纵向滚轮并抑制工作台横向滚动，不需要点击或取得焦点；保留原有触控板、输入控件和缩放交互，激活提示在现有标题预留位置仅显示中性的内联上下箭头图标。
- 周、日鼓轮都按真实日期顺序连续浏览，跨年动态渲染有界窗口并在中心跨过当前行窗口边界时更新，不循环、不重复日期。行和视口使用固定高度，当前周/今天身份以内联显示在真实行中；该行按逻辑日期 index 计算自然位置，正常位置可见时跟随内容，离开视口时同一 DOM 行按滚动方向夹到视口顶部或底部，不复制 DOM 行、不改变列表高度，也不保留底部返回控件。点击当前周/今天行平滑居中并打开对应计划或空态。无计划的周和日期可浏览并进入空态，只有明确创建动作才写入计划。滚轮使用阻尼平滑吸附，中心候选仅在滚轮静止至少 500ms 且运动结束后提交，中间日期不打开面板。用户选择周后平滑定位日鼓轮到已保存的周起始日或当前周起始设置；用户选择日期后选中日期及所属周，并让周鼓轮平滑对齐。程序定位不发出新的用户提交，避免反馈循环；键盘方向键、Page、Home（今天/当前）沿用同一 500ms quiet + settled 提交条件，Enter/Space 和点击行直接选择，减少动态效果时只切换视觉动画而不改变滚轮防抖。
- 鼓轮滚动的帧更新保持固定的有界 DOM：连续帧只更新已经渲染行的 transform/opacity，不每帧重建 React 日期行或重复格式化日期；只有中心跨过当前行窗口边界时才更新有界行集合，复用已有格式化标签，仅为新增行格式化，不引入额外批量缓冲层。周、日仍保留至少 500ms wheel quiet 与运动 settled 后提交、同一 current 行夹边/回中和无过期联动。停稳后的周、日面板同步保持原位内容：目标面板的任务和专注块数据全部就绪前，旧内容保持可见但不可编辑；就绪后仅让内容约 160ms ease-in 淡出至 opacity 0，卡片边框和背景始终不透明，再将目标内容原位以约 260ms 缓启动缓停止淡入至 opacity 1。不得对整卡使用 translate 或 scale；卡片自然高度只在切换期间约 260ms 平缓插值并遵守可用高度上限，不短暂坍塌。快速连续导航从当前显示状态接续，取消或忽略过期过渡，只保留最新目标和单一 live 内容树；减少动态效果时在数据就绪后立即替换。
- 计划卡使用随内容增长的自然高度，最小约 360px，并受工作台可用高度上限约束，不能造成窗口级纵向溢出或始终拉伸到整屏；达到上限时仅中部任务行滚动，卡片头部和底部工作量摘要保持固定。专注块侧卡使用相同的有界卡片规则和独立滚动区，保留鼠标主键点击激活行为。
- 带关联后代的目标和计划删除前展示递归影响，确认后按所示范围删除子目标及相关专注块。
- 规划工作区中的任务、目标、稍后任务和专注块仅在删除操作成功且对应查询结果真正移除条目后原位退场：内容约 160ms 淡出，高度或占位约 260ms 收拢，分段重叠并让后续行连续让位；退出节点不可编辑、拖拽或聚焦。取消或失败保持原内容，递归删除同批退场，快速独立删除不影响新加入或恢复的同 ID 条目；减少动态效果时立即移除。整张计划删除沿用 PlanTransition 平滑切换到下一个计划或空态，包括长期周期，不改变删除 token、确认流程或数据库契约。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `planning-cycles`: 自定义长期起止日期与检查安排，删除影响确认。
- `task-graph`: 目标删除的递归影响及确认边界。
- `planner-workspace`: 主工作台鼠标滚轮默认横向浏览，计划卡和专注块内容区按鼠标主键点击后进入纵向滚动；周、日导航使用悬停独占滚轮的连续日期鼓轮，支持延迟提交、空态、固定高度、动态有界窗口、帧级性能约束、轻量面板过渡和无反馈循环的周日联动；计划卡和专注块卡按可用高度自然增长并在各自内容区滚动。

## Impact

依赖 `rebuild-baseline`、`add-application-i18n` 及既有计划关联。涉及周期领域/持久化、创建弹窗、关联工作台滚动容器、周导航、目标/周期删除预览与确认。周导航只改变现有工作台的呈现和选择行为，不增加数据或后端契约。不改三档产品月（每月 28 天）的既有含义。
