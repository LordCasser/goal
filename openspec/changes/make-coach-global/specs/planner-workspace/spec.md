## MODIFIED Requirements

### Requirement: 计划区的 AI 规划入口

长期、周和日计划区域 SHALL 提供符合现有轻量次按钮样式的 Plan with AI 入口。入口 MUST 同时满足激活模型配置已测通、设置选项已开启；设置 SHALL 默认开启并允许关闭。入口使用全局 Coach 会话，点击时捕获当前页面选择快照。

#### Scenario: 上下文入口显现
- **WHEN** 用户的指针进入可编辑计划区或键盘焦点位于该区域，且显示条件成立
- **THEN** 在任务列表下显现 Plan with AI，布局不跳动；离开区域后轻量收起
- **AND** 专注块区域、Later、已结束计划和隐藏视图不显示此入口

#### Scenario: 开始当前周期的规划
- **WHEN** 用户点击 Plan with AI
- **THEN** Coach 打开全局会话并以点击瞬间的 `view`、长期/周/日选中项、`week_starts_on` 和 `selected_date` 开始相应规划，已有全局历史保留
- **AND** 请求期间提供等待反馈并防止重复发起；错误可见，本地任务保持可用

#### Scenario: 切换周期不重建 Coach
- **WHEN** 用户在规划回合之间切换长期、周或日计划
- **THEN** Coach 历史、草稿、消息滚动位置和未完成回合保持不变
- **AND** 新页面选择只作为下一次显式发送的快照

#### Scenario: 设置关闭
- **WHEN** 用户关闭设置中的计划区 AI 规划入口
- **THEN** 所有计划区域入口立即隐藏，重启后保持关闭，已有全局 Coach 仍可手动打开

#### Scenario: 显示条件的本地读取
- **WHEN** 界面决定是否显示入口
- **THEN** 只读取本地持久化验证状态与显示偏好，不访问钥匙串或发起网络探测

### Requirement: 固定顶栏

系统 SHALL 提供固定高度的应用工具栏，包含 Later、Workspace/Calendar 互斥页面标签、Coach/Issues 辅助面板入口及设置；全局 Coach 的待确认入口与 Coach 关联显示。应用工具栏在 macOS 与原生红绿灯融合，在 Windows 与右侧窗口控制融合为单行，在 Linux 位于系统标题栏下。工具栏高度 SHALL 由平台对应的布局变量控制，侧栏与主区 MUST 从应用工具栏下沿对齐；客户区之外的系统标题栏高度不属于客户区布局。

#### Scenario: macOS 左侧安全区
- **WHEN** macOS 常规窗口显示原生红绿灯
- **THEN** 应用栏保留专属左侧安全区，Later 排在安全区之后，所有应用控件避开系统按钮

#### Scenario: Windows 融合工具栏
- **WHEN** 应用正常运行在 Windows
- **THEN** Later 从正常左侧内边距开始，应用功能与右侧窗口控制共处一行；两组控件间有独立间隔，窗口控制不挤压或覆盖设置
- **AND** 不出现 macOS 专用空槽、重复标题或额外整行窗口栏

#### Scenario: Linux 工具栏
- **WHEN** 应用运行在 Linux
- **THEN** Later 从工具栏的正常左侧内边距开始，工具栏位于系统装饰下且为紧凑单行；不出现 macOS 专用空槽、重复标题或自绘系统关闭按钮

#### Scenario: 功能分组保持一致
- **WHEN** 用户切换平台、主题或打开辅助面板
- **THEN** Workspace/Calendar 的互斥选中与 Coach/Issues 的展开状态仍以不同控件分组表达，不合并成一种标签栏

#### Scenario: 侧栏与顶栏对齐
- **WHEN** 打开任意侧栏并调整窗口尺寸
- **THEN** 侧栏从应用工具栏下沿开始，不覆盖应用栏或系统窗口控制，也不为系统标题栏重复预留一行空间

#### Scenario: 跨页面待确认
- **WHEN** 全局 Coach 有待确认改动，用户切换 Workspace/Calendar 或长期、周、日选择
- **THEN** 顶栏仍显示待确认入口，入口数量与原提案一致，点击后可确认或放弃原目标
- **AND** 页面切换不生成对话请求

#### Scenario: 顶栏元素随状态变化
- **WHEN** 引导已完成、已跳过，或全局会话出现待确认改动
- **THEN** 引导状态不替代持久导航；待确认入口保持可见但不挤出页面标签、Issues 或设置，不增加整行状态栏

### Requirement: Agent 侧栏外壳

Agent SHALL 以右侧固定宽度的全局 Coach 侧栏出现，包含：一个标题栏（含标题与关闭按钮）、一个可滚动的消息区、一个固定在底部的输入区。侧栏打开时 MUST NOT 遮挡工作台的可操作区域；切换页面或计划时不重建侧栏内容。

#### Scenario: 打开侧栏
- **WHEN** 用户在工作台、Calendar 或任一计划页面触发某个 AI 入口
- **THEN** 侧栏打开同一全局会话，列的滚动位置保持，当前页面选择只作为本次入口动作的快照

#### Scenario: 关闭侧栏
- **WHEN** 用户关闭 Coach 侧栏
- **THEN** 工作台恢复原宽度，草稿、消息历史、阅读位置、在途回合和待确认入口保留，工具栏显示返回 Coach 的待确认入口

#### Scenario: 切换页面保持全局面板
- **WHEN** Coach 侧栏打开且模型回合或工具调用正在执行，用户切换 Workspace/Calendar 或其他计划
- **THEN** 侧栏不卸载、不取消回合，回复继续显示在原全局历史中
- **AND** 回合使用发送时页面快照，新的页面选择不改变在途工具目标
