## MODIFIED Requirements

### Requirement: 固定顶栏

系统 SHALL 提供固定高度的应用工具栏，包含相邻的 Later 与回收站入口、Workspace/Calendar 互斥页面标签、Coach/Issues 辅助面板入口及设置；Later 与回收站 SHALL 复用左侧抽屉空间，切换入口时只显示对应列表。待确认入口与全局 Coach 关联显示，并在页面切换后继续指向原提案目标。应用工具栏在 macOS 与原生红绿灯融合，在 Windows 与右侧窗口控制融合为单行，在 Linux 位于系统标题栏下。工具栏高度 SHALL 由平台对应的布局变量控制，侧栏与主区 MUST 从应用工具栏下沿对齐；客户区之外的系统标题栏高度不属于客户区布局。

#### Scenario: macOS 左侧安全区
- **WHEN** macOS 常规窗口显示原生红绿灯
- **THEN** 应用栏保留专属左侧安全区，Later 与回收站依次排在安全区之后，所有应用控件避开系统按钮

#### Scenario: Windows 融合工具栏
- **WHEN** 应用正常运行在 Windows
- **THEN** Later 与回收站从正常左侧内边距开始，应用功能与右侧窗口控制共处一行；两组控件间有独立间隔，窗口控制不挤压或覆盖设置
- **AND** 不出现 macOS 专用空槽、重复标题或额外整行窗口栏

#### Scenario: Linux 工具栏
- **WHEN** 应用运行在 Linux
- **THEN** Later 与回收站从工具栏的正常左侧内边距开始，工具栏位于系统装饰下且为紧凑单行；不出现 macOS 专用空槽、重复标题或自绘系统关闭按钮

#### Scenario: 功能分组保持一致
- **WHEN** 用户切换平台、主题或打开辅助面板
- **THEN** Workspace/Calendar 的互斥选中与 Coach/Issues 的展开状态仍以不同控件分组表达，不合并成一种标签栏

#### Scenario: 侧栏与顶栏对齐
- **WHEN** 打开任意侧栏并调整窗口尺寸
- **THEN** 侧栏从应用工具栏下沿开始，不覆盖应用栏或系统窗口控制，也不为系统标题栏重复预留一行空间

#### Scenario: 顶栏元素随状态变化
- **WHEN** 引导已完成、已跳过，或会话出现待确认改动
- **THEN** 引导状态不替代持久导航；待确认入口保持可见但不挤出页面标签、Issues 或设置，不增加整行状态栏

#### Scenario: 跨页面待确认
- **WHEN** Coach 在一个计划页面产生待确认提案，用户切换 Workspace/Calendar 或另一个周期
- **THEN** 待确认入口仍然可见，确认或放弃继续作用于原提案目标并进入全局聊天历史
- **AND** 页面浏览不生成 Coach 用户消息或模型请求

#### Scenario: 左侧抽屉切换
- **WHEN** 用户在 Later 与回收站入口间切换
- **THEN** 左侧同一位置只显示所选列表，主工作区不叠加第二条抽屉
