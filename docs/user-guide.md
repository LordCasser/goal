# Goal 使用说明

这份说明对应 Goal `v0.1.x`。

## 第一次启动

安装对应平台的包后启动应用。macOS 包目前没有 Developer ID 和 notarization，首次打开可能被 Gatekeeper 拦截。确认来源和校验值后，按 [Apple 的说明](https://support.apple.com/en-gb/102445) 到“系统设置 → 隐私与安全性”使用 **Open Anyway**。不需要也不建议关闭整个 Gatekeeper。

应用启动后会在本地创建数据库和 AI 配置。可以从长期目标开始，也可以直接创建本周或当天的独立事务。

## 界面语言

从 **设置 → 通用 → 语言** 选择 **简体中文** 或 **English**。切换即时生效，重启后保持，不会清空正在编辑的内容。首次启动按系统语言匹配，不支持的语言使用英语。任务标题、模型名、历史对话和自定义 persona/SKILL 保持原样；新 AI 回复默认使用界面语言，也可以在提问时明确要求其他语言。

In **Settings → General → Language**, choose **English** or **简体中文**. The change takes effect immediately and is saved for the next launch. Your plans, drafts and conversation history stay unchanged. AI uses the selected language by default; you can request another language in your message.

## 计划和任务

工作台（Workspace）按长期、周、日展示计划。周和日导航都是日期选择器式鼓轮：周、日期跨年按真实时间连续排列，只有中心跨过当前行窗口边界时才更新有界窗口，不循环也不重复。鼓轮行、视口和空态保持固定高度；当前周和今天以内联标签显示在真实行中，每行按逻辑日期 index 计算自然位置，正常位置可见时跟随内容，离开视口时同一行按滚动方向夹到视口顶部或底部，不插入重复列表行或底部返回控件。没有计划的周和日期仍可浏览并显示空态，只有明确的创建按钮才会写入计划。

鼠标指针悬停在周或日鼓轮上时，该鼓轮独占纵向滚轮并抑制工作台横向滚动，不需要先点击或取得焦点。滚轮会平滑吸附到中心行；只有滚轮静止至少 500 毫秒且运动结束后，中心周或日期才提交，中间经过的日期不会打开面板。点击行、Enter、Space 可以直接选择；方向键、Page、Home（本周/今天）沿用相同的 500 毫秒等待和运动结束条件。点击当前周或今天行会平滑居中并打开对应计划或空态。选择周后，日鼓轮平滑定位到该周保存的起始日或周起始设置；选择日期后会选中日期及所属周，并让周鼓轮平滑对齐。程序定位不会再次触发用户选择。启用减少动态效果时，视觉移动立即完成，但滚轮和键盘仍使用相同的等待时间。

快速滚动时，鼓轮只移动已经显示的有限日期行，不会每一帧重建日期行或重新格式化日期；只有中心跨过当前行窗口边界才会更新有限行，复用已有格式化标签，只为新增行格式化，不增加额外批量缓冲层，当前周/今天行仍保持同一行并在边缘夹住或回到中心。停稳后切换周/日计划时，旧内容会原位保留到目标面板的任务和专注块数据全部准备好，并且不可编辑；数据就绪后，内容约 160ms ease-in 淡出至 0，卡片边框和背景保持不透明，目标内容原位约 260ms 缓启动缓停止淡入至 1，卡片自然高度只在切换期间平缓插值并遵守可用高度上限。整卡不使用 translate 或 scale，也不短暂坍塌；连续快速选择从当前显示状态接续并只保留最新目标的一棵 live 内容树，减少动态效果会在数据准备好后立即替换。


计划卡会随任务量自然增长，至少保留约 360px 的阅读空间，并在窗口较矮时收缩到工作台可用高度，不会把整个窗口撑出纵向滚动。任务较多时，卡片顶部和底部的摘要保持可见，只有中间的任务行滚动；旁边的专注块卡也有自己的滚动区域。点击内容区后才会按工作台现有规则启用纵向滚轮。

任务有两种关系：

- **独立任务**：只属于当前周或当前日，不强行挂到长期目标。
- **关联任务**：通过父目标选择器关联到周目标或长期目标。长期目标颜色会沿关系显示，颜色只表达归属，不代表优先级分数。

任务可以直接编辑标题、完成状态、子任务、顺序和关联。需要先记下来的内容可以放进 **稍后（Later）**，之后再提升到某个长期周期。删除周期或有关联子项的任务时，确认框会列出完整影响范围，包括其他计划中的关联子目标、子任务，以及随计划删除的专注块。确认前关联内容若有变化，会更新范围并要求重新确认；取消不会删除。独立专注块不会因同日任务被删除而消失。

主工作台使用普通鼠标滚轮时默认横向浏览。计划卡和专注块的内容区需要鼠标主键点击后才上下滚动，标题或列表外点击会恢复横向浏览；对应标题旁只显示中性的“↕”图标，悬停可查看说明，辅助技术可读取相同标签。时间导航使用上面的悬停独占鼓轮规则，不需要点击激活。明显横向的触控板手势、输入控件和缩放操作保持原有行为。

长期周期、周周期和日周期有自己的日期和生命周期。结束的周期仍保留本地记录；日历会根据日期显示当前日计划。

长期周期可选 1 / 3 / 6 个月（4 / 12 / 24 周），也可选最后的 **自定义**，填写起止日期。进度检查支持 **定期检查**（每若干天或周）和 **指定一次**；创建前可预览检查日期，创建后点击周期日期旁的检查节奏查看详情。结束日期是复盘边界，中途检查位于结束日期之前。检查安排不会自动生成任务、专注块或提醒。

新建日计划默认没有专注块。只有明确启用“每天重复”的专注块才会自动出现在新日期；选择“停止重复”后，后续日期不再生成实例，已有记录保留。

## 日历和专注块

顶部切换到日历（Calendar） 后可以使用月视图或周视图。选中日期后，右侧有两个入口：

- **计划（Plan）**：查看当天任务、关联的周目标和长期目标。
- **排期（Schedule）**：查看当天时间轴。专注块可以先留在未安排区，再通过排期入口设置开始时间和时长；在浮层中调整开始时间与持续分钟数后，点击保存排期。

专注块的时长使用整数分钟。排期后，工作台的专注块区域会显示计划总时长。相邻或重叠的安排会在日历数据中保留，应用不会把它们悄悄改成另一个时间。

## 稍后（Later）

点击窗口顶部的 **稍后（Later）**，输入标题即可先保存一个待安排目标。新记录默认标为长期目标；从长期、周或日计划移入的条目会在行内保留“长期目标 / 周计划 / 日计划”类型提示。同一周期的子步骤会随根项保留嵌套；来自不同计划层级的项即使同时在 Later 中，也仍是各自的独立暂存项。

长期目标使用“安排到长期周期”，只有一个可用长期周期时直接安排，多个周期时选择目标。周计划使用“安排到本周”，日计划使用“安排到今天”；应用按本地日期和设置中的周起始日确定目标，已有周或日计划会复用，没有时与移动一起创建。安排成功后条目离开 Later；再次移入会按当时所属周期重新记录类型。旧数据没有类型信息时按长期目标处理，不推测历史来源。失败原因显示在对应行内，不会留下空周期。

## 配置 AI（BYOK）

Goal 不提供内置模型额度。AI 功能使用你自己配置的供应商和 API Key，费用和数据处理规则由你选择的供应商决定。

1. 打开右上角设置，进入 **AI 模型**。
2. 添加供应商，填写名称、Base URL、API 格式和至少一个模型 ID。支持 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses，也可以填写本地模型服务的 HTTP 地址。
3. API Key 只在需要时填写。如果服务需要额外 Header，在“请求 Header”中逐行填写名称和值；点击“测试并保存”，所有模型通过后才保存。
4. 选择当前供应商 / 模型。需要时打开“计划区 AI 规划入口”，让 Workspace 显示 **用 AI 规划**。

模型的上下文窗口、最大输出 token、输入类型和是否支持工具是配置元数据。应用不会因为列表里有另一个模型就自动替换你选中的模型。

本地 OpenAI 兼容服务通常填写 `http://localhost:端口/v1`，协议选择服务实际支持的格式，模型 ID 与服务中的名称一致。Base URL 不要包含 `/chat/completions` 等具体接口后缀，Goal 会按协议追加。连接测试会逐个模型发送流式生成请求，因此仅用 curl 成功读取 `/v1/models` 不代表模型生成接口可用。localhost 和回环 IP 自动直连，不依赖终端的 `NO_PROXY`；远程服务仍使用系统代理。

供应商表单的“高级设置”可选择连接方式：

- **自动**（默认）：本机地址直连，其他地址沿用系统/环境代理。
- **直接连接**：此供应商请求不使用代理。
- **指定代理**：其他地址只使用填写的代理，不可达时报告失败，不自动直连。本机回环地址仍始终直连。

代理地址包含协议、主机和显式端口，例如 `http://127.0.0.1:7890` 或 `socks5h://127.0.0.1:1080`，支持 HTTP、HTTPS、SOCKS5、SOCKS5h。当前支持无需认证的代理，请勿在地址中填写账号密码、接口路径或参数。修改后点击“测试并保存”，失败会保留草稿与原先已保存的配置。


请求 Header 对同一供应商的全部模型生效，也用于连接测试。值默认隐藏并保存在系统凭据存储中；重新打开时不会回显，留空保留同名已有值，填写新值替换，删除行则移除。更改名称需要重新填写值。名称不区分大小写，不能重复；值不能包含换行或非 ASCII 字符。

自定义 `Authorization`、`x-api-key` 或 `anthropic-version` 会覆盖同名默认 Header。`Content-Type`、`Accept`、`Host`、长度和连接管理等传输 Header 由 Goal 管理。测试失败时原配置不变，表单草稿保留。使用直接的 API 地址；请求不会跟随 HTTP 重定向转发凭据。

## 使用助理（Coach）

点击顶部 **助理（Coach）** 可在有无计划的页面打开同一条全局对话。切换长期、周、日、Workspace 或 Calendar 时，历史、草稿、阅读位置和进行中的回复继续保留；页面切换本身不会写入消息或发起请求。发送消息时，应用会把当前页面和选择快照传给 Coach：页面类型、当前活动周期、选中的长期/周/日计划、周起始日和日期；没有计划的字段显示为 `null`。在途工具继续使用发送时的目标范围。

涉及本地数据写入时，助理先展示待确认的预览。检查变更对象、前后内容和所属周期后，再选择确认或放弃。确认入口跨页面保持可见，确认始终作用于原提案目标，不按当前页面重定向；确认后的回执会进入全局聊天历史。对话中的工具结果会折叠成状态行，不直接把 JSON 铺满界面。

助理支持长期规划、周规划、日规划、目标澄清、优先级、复盘、时段分析和计划问题等技能。技能只决定当前工作流，不能绕过应用的确认边界。

### 上下文保留时间

在 AI 设置中可以修改 **助理上下文保留时间**，范围是 1–1440 分钟，默认 15 分钟。超过这段时间没有新对话后，应用会清理全局会话消息、活动技能和错误；正在执行的回合不会被中途截断，页面阅读和切换也不会续期。重新打开助理会继续全局会话，直到它按 TTL 清理。

## 计划问题（Issues）

打开计划问题可以查看当前计划的规则提示。它会显示任务数量、当日负荷、目标信息等问题，并支持定位任务、与助理讨论或选择忽略原因。

只有配置并测通模型后，才能点击 **AI 检查**。AI 检查结果会标明检查状态和模型；计划或模型发生变化后，旧结果会标记为需要重新检查。没有待办时，应用不会伪造一份“检查通过”的结果。

## 自定义 persona 和 skills

Goal 首次启动时会创建以下本地配置：

```text
~/.goal/persona.md
~/.goal/skills/<skill-name>/SKILL.md
```

`persona.md` 控制回答风格；`SKILL.md` 控制对应工作流的说明。已有文件不会被覆盖，应用每次生成前读取最新 UTF-8 内容；首次创建的 `coach/SKILL.md` 使用英语默认提示。当前内置技能目录包括 `coach`、`goal-clarification`、`long-term-planning`、`weekly-planning`、`daily-planning`、`prioritization`、`cycle-review`、`period-analysis` 和 `planning-issues`。

这些文件会成为 AI 请求的一部分。不要在 persona 或 skill 文件里放 API Key、密码、Cookie 或其他不应发送给模型供应商的内容。

## 数据和隐私

任务、周期、日历、专注块、设置和会话默认留在本机。API Key 使用操作系统凭据存储，不写进普通配置文件。AI 请求的数据边界、供应商保存责任和本地文件说明见 [`docs/privacy.md`](privacy.md)。

`v0.1.x` 不包含语音输入、云同步或自动更新通道。需要升级时，请从 [Releases](https://github.com/LordCasser/goal/releases/latest) 获取新资产，并按平台说明安装。

## 开发和问题排查

开发者命令、平台目标和桌面打包限制见 [`docs/desktop-build.md`](desktop-build.md)。常用检查命令：

```sh
npm ci
npm test
npm run tauri dev
cargo test --manifest-path src-tauri/Cargo.toml --locked
```

如果 AI 页面显示“请选择已测通的模型”，先检查 Base URL、API 格式、模型 ID 和凭据，再重新运行连接测试。连接测试失败不会覆盖原来的已保存配置。
