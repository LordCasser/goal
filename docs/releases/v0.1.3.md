# Goal v0.1.3

v0.1.3 deepens the planning workflow and makes provider routing more explicit.

## Highlights

- Associate a focus block with an optional task from the same day, derive task focus totals, and keep deletion and movement behavior consistent with that relationship.
- Add provider-level connection modes for automatic, direct, or explicitly configured proxy routing, including consistent behavior for connection tests and model requests.
- Improve planner date, week, and transition navigation, focus-block editing, drag-and-drop behavior, and removal-impact presentation.
- Extend backend AI/network boundaries, sampling tests, and localized copy for the new planning and provider flows.
- Keep the English README as the default, provide `README_zh.md`, and show the Goal Workspace screenshot at the top of both files.

## Platform notes

The release workflow builds macOS, Windows, and Linux for both amd64 and arm64. macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Windows/Linux native GUI acceptance, including physical drag-and-drop and wheel behavior, remains a separate follow-up and is not implied by CI success.

Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope.
