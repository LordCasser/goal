# Goal v0.1.4

v0.1.4 is a maintenance release published from the v0.1.3 baseline.

## Release scope

- Refresh the application, desktop configuration, lockfiles, README files, and release contract to v0.1.4.
- Keep the English README as the default, provide `README_zh.md`, and show the Goal Workspace screenshot at the top of both files.
- Preserve the v0.1.3 feature set and release packaging contract across macOS, Windows, and Linux for amd64 and arm64.

The uncommitted Later plan-type work discussed immediately before this release is intentionally not included in v0.1.4.

## Platform notes

macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope.
