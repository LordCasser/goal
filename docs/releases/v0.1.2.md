# Goal v0.1.2

v0.1.2 extends the planning workflow and refreshes the public documentation.

## Highlights

- Add custom planning-cycle controls with repeat/once progress checks and bounded date previews.
- Improve task and calendar drag-and-drop behavior, cross-level linking, focus-block scheduling, and time editing.
- Add guarded task/cycle/focus-block deletion with impact previews and stale-preview protection.
- Support validated custom provider request headers with shared redaction and credential-forwarding boundaries across the supported API formats.
- Refine workspace wheel routing, desktop shell permissions, layout behavior, and platform-specific configuration.
- Make `README.md` English by default, add `README_zh.md`, and place a Goal Workspace screenshot at the top of both files.

## Platform notes

The release workflow still builds macOS, Windows, and Linux for both amd64 and arm64. macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Windows/Linux native GUI acceptance, including physical drag-and-drop and wheel behavior, remains a separate follow-up and is not implied by CI success.

Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope.
