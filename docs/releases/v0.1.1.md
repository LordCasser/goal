# Goal v0.1.1

v0.1.1 修复 Calendar 整日拖动时重复创建 Focus block 的问题。拖动已有计划或模板实例后，不会再因为重复实例化而产生额外的 Focus block；已有 Focus block、模板关联和计划数据会保留。

新增完整的简体中文与英语界面，可在「设置 → 通用 → 语言」即时切换并保存。工作台、日历、Coach、模型设置、提醒和操作确认采用统一语言资源；日期、时长和数量跟随界面语言。任务标题、用户输入、历史对话和自定义 persona/SKILL 保持原样。内置 SKILL 和默认 persona 使用英语编写。AI 生成入口以界面语言作为默认回复语言，用户仍可明确要求其他语言。

同时修复待确认操作的目标被手动删除后，整个确认列表无法读取的问题；目标消失后仍可拒绝该操作，批准时继续校验目标。

中文术语统一为“专注块”，并统一使用“稍后”“助理”“用 AI 规划”等功能名称。月视图的专注进度改为单行图标与完成比，去除顶部重复计数，避免中文窄卡片中的断词和拥挤。

跨平台复核同时统一应用内选择框，修复排期浮层拦截时间/时长输入按键的问题。同时修正 Windows 构建脚本的 npm 调用，配置文件连续保存支持含中文和空格的路径。通知权限不再伪报已授予，系统提交失败会记录，并保留应用内提醒。运行时基线收敛为 macOS 13.3+、Windows WebView2 111+，与共享 UI 的浏览器能力要求保持一致。

发布矩阵沿用三平台双架构：

- macOS x86_64 与 arm64：DMG
- Windows x86_64 与 arm64：NSIS 安装包
- Linux x86_64 与 arm64：AppImage 与 deb

发布资产包含八个安装包和 `SHA256SUMS`。这些是发布矩阵目标，最终构建状态以 workflow 结果为准。

macOS 继续使用固定自签名证书和 designated requirement，不是 Apple Developer ID，也未经公证；从旧 ad hoc 包迁移时已有钥匙串项目可能需要首次授权。Windows 安装包继续未签名。Windows 和 Linux 的真实安装、窗口控件、DPI、桌面会话及辅助功能验收仍需按平台完成。
