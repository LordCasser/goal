# Goal v0.1.7

v0.1.7 adds calendar time planning and clearer task continuity across planning cycles.

## Highlights

- View daily plans in month and week calendars, move a day plan to another date with an explicit conflict choice, and arrange focus blocks on a daily timeline.
- Edit focus block times and daily plan dates through clear controls instead of cross-view drag operations.
- Add per-task notes and open task details by double-clicking; daily task details show matching work recorded across dates.
- Optionally carry unfinished weekly and daily tasks into the next cycle, preserving parent relationships and avoiding duplicates.
- Show the Later task count and configure it alongside automatic carry-forward settings.
- Add a shared application context menu with mouse and keyboard access, including text editing actions.
- Keep task order and the persistent empty entry row predictable when tasks move between Later and a plan.

## Platform notes

The release workflow builds macOS, Windows, and Linux for both amd64 and arm64. macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope. Manual native acceptance of context menus, clipboard access, keyboard focus, and window dragging remains platform dependent.
