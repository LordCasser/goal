# Goal v0.1.8

v0.1.8 makes planning edits safer and brings long-term cycles, task details, reminders, and date/time entry into a more consistent workflow.

## Highlights

- Move deleted goals, plans, tasks, focus blocks, and reminders into the Recycle Bin. Restore items to their original plan when possible, or permanently delete them after confirmation.
- Create long-term cycles without a fixed end date and choose progress checks independently from the cycle end date.
- See directly linked child items and their plan dates in long-term and weekly task details.
- Use shared in-app date and time pickers for cycle setup, reminders, calendar moves, and schedule editing.
- Improve task continuity and cycle controls across Workspace, Calendar, reminders, and Coach-approved actions.

## Platform notes

The release workflow builds macOS, Windows, and Linux for both amd64 and arm64. macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Automated and integration coverage is included in the release workflow. Manual acceptance is still outstanding for the Recycle Bin's confirmed permanent-delete path and large-plan snapshot size/performance; those checks are not represented as completed. Full native GUI acceptance on every supported platform remains platform dependent.

Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope.
