# Goal v0.1.5

v0.1.5 consolidates the current workspace into a complete cross-platform release.

## Highlights

- Add a local-first Coach with structured skills, planning context, previewed actions, and persisted global conversation history.
- Expand planning, Calendar, Later, reminders, reviews, proposals, focus blocks, and deletion workflows with stronger lifecycle and relationship handling.
- Add explicit provider connection modes, request headers, network boundaries, localized interface copy, and platform-specific desktop behavior.
- Preserve Later item planning type metadata so long-term, weekly, and daily items can be arranged at the appropriate level.
- Keep the English README as the default, provide `README_zh.md`, and show the Goal Workspace screenshot at the top of both files.

## Platform notes

The release workflow builds macOS, Windows, and Linux for both amd64 and arm64. macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope.
