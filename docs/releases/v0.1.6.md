# Goal v0.1.6

v0.1.6 improves relationship-aware planning and the daily planning workspace.

## Highlights

- Allow daily tasks to link directly to long-term goals without creating an artificial weekly task.
- Keep copied tasks, cross-cycle roots, child steps, and persistent empty input rows in the correct order.
- Add an optional relation-line setting, resilient cross-panel task reveal, and clearer clipped relationship endpoints.
- Show the linked long-term goal as a contextual tooltip when a daily task is hovered or focused.
- Include the direct daily-to-long-term relationship in Calendar goal context and keep English and Simplified Chinese UI copy aligned.
- Add frontend and Rust regression coverage for relationship validation, positioning, settings persistence, tooltips, and relation rendering.

## Platform notes

The release workflow builds macOS, Windows, and Linux for both amd64 and arm64. macOS packages use the fixed self-signed identity and are not notarized; Windows installers remain unsigned. Voice input, cloud sync, automatic updates, and account/telemetry services remain outside the current release scope.
