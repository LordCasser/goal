# Goal v0.1.0

Goal v0.1.0 是一个本地优先的个人规划应用。应用、窗口、系统菜单和安装包统一使用 **Goal**。

## 主要能力

- 把长期目标、周计划和日计划连接在同一条计划链上。
- 支持独立存在的临时任务，也支持任务与上层目标建立关系。
- 在 Workspace 中编辑、排序和完成任务，并使用 Do Later 暂存暂不安排的事项。
- 在 Calendar 中查看月/周计划，在单日视图安排 Focus 专注块、时间和时长。
- 配置自己的云端或本地模型（BYOK），支持 Anthropic Messages、OpenAI Chat Completions 和 OpenAI Responses 三种 API 格式。
- 使用 Coach 进行规划、目标澄清、优先级、复盘和时段分析。会改变本地数据的 AI 操作先进入预览和确认流程，用户确认后正式生效。
- 编辑 `~/.goal/persona.md` 和 `~/.goal/skills/` 下的文件，自定义 Coach 的回答风格与工作流。

## 发布资产

发布工作流定义了三个平台、六个架构目标和八个安装包：

- macOS x86_64 与 arm64：DMG
- Windows x86_64 与 arm64：NSIS 安装包
- Linux x86_64 与 arm64：AppImage 与 deb

Release 提供 `SHA256SUMS` 校验文件。发布流程要求六个目标全部构建成功，并通过实际程序架构和完整产物清单校验。

## 平台说明

macOS 使用固定自签名证书和 designated requirement，保持同一签名更新的钥匙串身份；它不是 Apple Developer ID，也未经公证。旧 ad hoc 包迁移到固定签名包时，已有钥匙串项目可能需要首次授权。Gatekeeper 可能要求用户在系统设置中允许打开应用。

Windows 安装包未签名。Windows 和 Linux 的真实安装、窗口控件、DPI、桌面会话及辅助功能验收仍有限，发布矩阵本身不替代这些 GUI 验收。

Linux 凭据运行需要用户会话中的 Secret Service，例如 `gnome-keyring`；应用不会把凭据回退写入明文文件或数据库。

## 当前范围

语音输入、云同步和自动更新尚未交付。Goal 不提供账户体系或遥测；AI 请求只会在用户配置并主动调用供应商时发生。
